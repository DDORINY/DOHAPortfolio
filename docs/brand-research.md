# WOORIEN Brand Research

> 조사 기준일: 2026-09-11 / Personal Project / Concept Proposal / Unofficial

## 브랜드 핵심 이해

우리엔은 동물 전용 영상진단 의료기기와 소프트웨어를 개발·판매·서비스하는 기업이다. 사업은 `MyVet Imaging` 영상 솔루션, `PMS 365 + e-Friends` 동물병원 운영 플랫폼, `Woorien Pharm` 의약품 유통, `Woorien App` 보호자 서비스로 이어진다. 즉 장비 한 종류보다 동물병원의 진료·운영·영상·약품·보호자 접점을 연결하는 VET 전문 기업으로 보는 편이 정확하다.

현재 AI 방향은 `woorien ZERO`에서 구체적으로 드러난다. ZERO는 AI 음성 차팅 `weVoice`, 건강검진 리포트 `CLAiR`, 보호자 커뮤니케이션을 하나의 생태계로 제시한다. 따라서 포트폴리오 주제는 막연한 미래형 AI보다 실제 병원 업무 흐름을 연결하고 수의사의 집중을 돕는 기술에 두는 것이 적합하다.

주 고객은 동물병원 원장, 수의사, 병원 운영 관계자다. Woorien App은 보호자까지 연결하지만 이번 채용 포트폴리오의 Primary Target은 B2B 실무 사용자로 잡는다.

## Visual Tone 분석

공개 홈페이지와 콘텐츠는 제품 설명이 중심인 의료 B2B 커뮤니케이션이다. 기업·제품 정보, 기능 목록, 장비 및 UI 이미지가 명확하게 나뉘며 신뢰와 실용성을 우선한다. 우리엔 소식은 제품 출시뿐 아니라 사용 팁과 개원 세미나처럼 현장 친화적인 어조도 함께 사용한다.

로고와 정확한 브랜드 컬러 수치는 공개 Brand Guideline으로 확인하지 못했다. 따라서 아래 내용은 공식 가이드가 아니라 공개 웹 경험을 바탕으로 한 포트폴리오용 해석이다.

- 유지할 요소: 깨끗한 여백, 명확한 정보 구획, 의료 전문성, 제품 중심의 구체성, 수의사에게 직접 말하는 실용적 어조
- 확장할 요소: 제품 사이의 연결, 진료 데이터의 이동, 음성에서 차트로 바뀌는 과정, 사람-동물-기술의 관계
- 줄일 요소: 의료기기 사진만 연속되는 카탈로그 인상, 일반적인 파란색 테크 그라데이션, 장식적인 AI 회로·로봇 이미지

## 디자인 질문에 대한 결론

- 가장 강한 이미지: 현재 사업 기반은 의료/동물병원이고, 최근 성장 메시지는 IT/AI와 플랫폼 연결이다.
- 필요한 인상: 정확하고 안정적이되 현장을 이해하며, 수의사의 시간을 되돌려주는 실용적인 파트너.
- 유지할 요소: 전문성, 명료한 계층, 제품/기능의 현실성, 사람과 동물의 건강이라는 목적.
- 확장할 요소: `연결`과 `흐름`을 하나의 유연한 그래픽 시스템으로 만들어 디지털·인쇄·공간에 적용.
- AI 표현법: 회로나 네온 효과 대신 음성 파형이 구조화된 기록 카드와 데이터 라인으로 정돈되는 변환을 보여준다.
- 딱딱함을 줄이는 법: 차가운 블루만 쓰지 않고 따뜻한 크림 배경과 생기 있는 그린을 결합하며, 실제 진료 순간의 손·시선·동물 디테일을 사용한다.

## 채용 포트폴리오 Target

Primary Target은 우리엔 마케팅팀과 채용 검토자다. 이들이 짧은 시간 안에 다음을 확인하도록 설계한다.

1. 수의 B2B 브랜드를 이해했다.
2. 하나의 KV를 카드뉴스, 뉴스레터, 행사, 인쇄, 웹으로 확장할 수 있다.
3. 생성형 AI를 결과물 생성기가 아닌 디자인 업무 도구로 통제한다.
4. 반응형 UI를 직접 구현할 수 있지만 디자인이 주인공이다.

Secondary Audience는 콘셉트 캠페인의 실제 수용자인 동물병원 원장과 수의사다.
