# Project 03 — Saved Song / AI Creative Iteration

## Definition
AI-assisted Content Planning / Visual Direction / Creative Iteration.
Personal Creative Case: 저장한 노래 — Saved Song Cover Artwork.
AI IS A TOOL. DIRECTION IS HUMAN.
생성 결과의 비교, 판단, 수정과 최종 선택을 보여주는 AI-assisted Creative Direction 사례입니다.

## Creative Flow
BRIEF → GENERATE → REVIEW → REFINE → FINAL.
결과 기준 설정 → 초기 결과 생성 → 문제 확인 → 방향 수정 → 최종 선택.

## Initial Review
TOO EXPLICIT. Subject-heavy / Over-staged / Generic AI Mood.
인물이 중심이 되고 소품과 연출이 많아 곡의 감정보다 음악 작업실 설정이 먼저 읽혔습니다.
SUBJECT: 인물 중심 / STAGING: 많은 소품 / MOOD: 감정보다 설정.

## Direction Change
LESS SUBJECT. MORE MEMORY.
REMOVE Person / REDUCE Props · Decorative Copy /
KEEP Warm Light · City · Workspace / ADD Negative Space · Personal Mood.

## Revision Review
REDUCE. No Subject / Fewer Elements / More Space.
인물을 제거하고 밤의 작업 공간에 집중했지만 장비와 정돈된 연출이 중심으로 남았습니다.
KEEP Late Night · Workspace · Warm Light · City.
REFINE Composition · Visual Noise · Personal Detail · Emotional Distance.

## Final Direction
KEEP THE MEMORY.
생활감과 여백을 중심으로 ‘다시 꺼낸 미완성 음악’의 감정을 최종 선택했습니다.
Late Night / Personal Space / Memory / Warm Light / City.
Result: Saved Song / Cover Artwork.
오류 수정이나 AI 품질 점수가 아닌 Creative Direction의 판단 과정으로 표현합니다.
프롬프트 전문과 가상 점수는 공개하지 않습니다.
