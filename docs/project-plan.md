## 범위
기존 Foundation의 HTML/CSS/Vanilla JS, 공통 UI와 GitHub Pages 설정을 유지합니다.
Experience는 회사·기간·역할을 요약하고 Project 02는 업무 방식과 사례를 기록합니다.

- Project 01 / OFFBEAT = Original Music Release & Content Brand.
  Category: Original Music · Release Content · Digital Content Planning.
  Type: Personal Concept Project / 2026.
  Role: Content Planning · Music Direction · Content Direction · Visual Planning · AI-assisted Production.
  MUSIC → IDENTITY → VISUAL → CONTENT → RELEASE.
  첫 실제 콘텐츠는 RELEASE 001 — 저장한 노래이며, 커버와 MP3가 존재합니다.
  기존 음악 추천 기획을 폐기하고 Release Campaign을 계획합니다.
  [Release System](offbeat-release-system.md)이 최신 기획 기준입니다.
- Project 02: Operate → Organize → Create → Respond → Improve → Share.
  사용자 확인 경력 범위를 바탕으로 업무 흐름을 표시합니다.
  Detail은 Context / Action / Review 및 Case Material을 갖추되 사례 내용은 TBD입니다.
  재구성 샘플은 원본과 구분하고 내부 자료·개인정보를 포함하지 않습니다.
- Project 03: Brief → Direction → Prompt → Generation → Selection → Revision → Final.
  목적, 기준, 비교, 문제 발견, 수정, 재검토, 최종 선택을 기록합니다.
- 기획상 저장한 노래는 OFFBEAT RELEASE 001입니다.
  현재 웹에서는 AI Case와 Process 사이의 secondary content로 남아 있습니다.
  메인 12개 navigation은 유지합니다. 사용자가 제공한 실제 커버와 MP3를 연결했습니다.
  [Side Project 기록](side-project-music.md)에 현재 구성과 이전 코드를 보존합니다.
