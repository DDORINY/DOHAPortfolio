# Project 02 — MORU / CALM BARRIER SERUM
## Definition
MORU는 실제 판매 브랜드가 아닌 포트폴리오용 Concept Product Brand입니다.
CALM BARRIER SERUM / Daily Moisture Serum / Skincare · Beauty / 2026.
Commercial Content · E-commerce / Work Experience Based Reconstruction.
온라인 쇼핑몰 운영, 상품 콘텐츠 관리, 이미지 제작과 프로모션 지원 경험을 바탕으로
하나의 Concept Product를 여러 채널의 실제 디자인 결과물로 확장한 재구성 Case입니다.
실제 회사의 MORU 작업 이력이나 판매·성과를 의미하지 않습니다.

## Product Copy
- 매일의 피부에, 필요한 만큼.
- LESS NOISE. MORE COMFORT.
- FOR A CALMER EVERYDAY SKIN
Hero 이미지에 캠페인 카피가 포함되어 HTML에서 크게 반복하지 않습니다.

## Web Architecture
06 MORU: Reconstruction label → 제품명·metadata → 큰 Product Master →
짧은 카피·Concept 고지·경력 연결 → Product Hero → 3개 Message → Content Flow.
08 Commercial Case: FROM PRODUCT TO CONTENT. → Detail → Desktop → Mobile → Story.
실제 결과물 6개를 표시합니다. Social 01–03 원본은 삭제하지 않고 기본 화면에서만 제외했습니다.
Detail은 중앙 정렬, Mobile/Story는 한 쌍으로 구성해 원본 비율을 유지합니다.
12개 navigation 번호·ID를 유지하며 06 label은 MORU입니다.

## Visual Direction / Quality
Bright / Clean / Beauty / Commercial / Product-focused.
기존 Foundation palette는 유지하며 MORU 이미지를 중립적인 프레임에 배치합니다.
Visual 75–80% / Copy 20–25%는 구성 목표이며 계측한 비율을 뜻하지 않습니다.
원본 비율, contain, 명시적 width/height, lazy loading, async decoding을 적용합니다.
추가 overlay·blur·opacity 효과를 넣지 않습니다.

## No Invented Claims
임상시험, 개선율, 보습 지속 시간, 장벽 개선 수치, 성분 함량·효능 보증,
피부과·저자극 테스트, 인증, 용량, 가격, 할인, 판매량, 리뷰·평점, 전환율, CTR, 매출을 만들지 않습니다.
제공 이미지 안의 표현은 원본 그대로 표시하며 HTML에는 지정된 Message 3개 외 새 효능을 추가하지 않습니다.
위 dimensions는 이미지 크기이며 제품 사양이 아닙니다.
