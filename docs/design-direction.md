## Campaign Concept 3안

### A. Care in Focus — 추천안

- Concept Name: `Care in Focus`
- Target: 진료와 기록을 동시에 수행하는 수의사 및 동물병원 원장
- Core Message: 연결된 AI 도구가 반복 기록을 정돈해 수의사가 진료와 보호자에게 더 집중하도록 돕는다.
- Main Copy 후보: `진료에 더 가까이. 기록은 더 자연스럽게.`
- Visual Direction: 실제 진료 장면 위로 음성 파형이 정돈된 차트 모듈로 전환되는 한 방향의 흐름
- Color Direction: Deep Navy `#102A43`, Signal Green `#25B78A`, Warm Ivory `#F5F1E8`, Sky `#BFE8F3`, Graphite `#263238`를 탐색 시작값으로 사용
- Typography Direction: 단단한 Neo-grotesk 계열 한글 Sans + 수치/라벨용 Condensed Sans. 실제 폰트는 라이선스 확인 후 확정
- Image Direction: 수의사의 손·시선·대화, 동물의 자연스러운 표정, UI 디테일을 가까운 크롭으로 사용
- Graphic Motif: `Voice → Note → Care`를 잇는 Flow Line, pulse, rounded record card
- 적용 콘텐츠: 전 산출물, 특히 KV·카드뉴스·랜딩·세미나
- 장점: AI, 동물병원, 인간적 신뢰를 균형 있게 결합하고 매체 확장성이 높음
- 단점: 흐름 그래픽이 평범한 SaaS 비주얼이 되지 않도록 고유한 형태 설계 필요

### B. One Clinic, One Flow

- Concept Name: `One Clinic, One Flow`
- Target: 병원 운영 전체를 관리하는 원장 및 실무자
- Core Message: 흩어진 진료·영상·운영·보호자 접점을 하나의 흐름으로 연결한다.
- Main Copy 후보: `병원의 모든 흐름을, 하나로.`
- Visual Direction: 여러 모듈이 하나의 유기적 시스템으로 결합되는 정보 지도
- Color Direction: Cobalt Blue, Aqua, White, Lime accent
- Typography Direction: 중립적 Sans와 데이터 라벨 중심의 정교한 정보 체계
- Image Direction: 제품 UI, 장비, 병원 공간을 구조적으로 병치
- Graphic Motif: 연결 노드, orbit, modular tile
- 적용 콘텐츠: 카탈로그·부스·랜딩·Design System에 강함
- 장점: 우리엔의 넓은 사업과 ZERO 생태계를 가장 잘 설명함
- 단점: 특정 AI 캠페인의 감정적 집중도가 낮고 기업 브로슈어처럼 보일 수 있음

### C. A Clearer Tomorrow

- Concept Name: `A Clearer Tomorrow`
- Target: 새로운 진료 기술에 관심 있는 수의사와 예비 개원 원장
- Core Message: 복잡한 진료 정보가 더 선명한 판단과 설명으로 이어진다.
- Main Copy 후보: `복잡한 진료를, 더 선명한 경험으로.`
- Visual Direction: 흐릿한 데이터/영상이 선명한 진단 프레임으로 포커싱되는 전환
- Color Direction: Charcoal, Clinical White, Cyan, Soft Coral accent
- Typography Direction: 높은 대비의 Display Sans + 차분한 본문 Sans
- Image Direction: X-ray·초음파의 질감과 동물 실루엣을 추상적으로 재해석
- Graphic Motif: focus frame, scan line, layered transparency
- 적용 콘텐츠: KV·컨퍼런스·X배너·Before/After에 강함
- 장점: 강한 시각 효과와 영상진단 사업의 전문성을 보여줌
- 단점: 의료기기 브랜드 인상이 강하고 AI 차팅·보호자 연결을 담기 어려움

## 최종 추천: Care in Focus

채용공고가 요구하는 브랜드 콘텐츠, 행사, UI/UX, AI 활용을 한 이야기 안에서 가장 자연스럽게 보여준다. 우리엔의 의료 전문성을 유지하면서 `수의사가 진료에 집중하도록 돕는 연결 기술`로 확장할 수 있어 너무 딱딱하거나 일반적인 AI 기업처럼 보이지 않는다.

Visual rule은 `Warm Clinical + Human Technology`다. 넓은 Ivory 여백과 Deep Navy로 신뢰를 만들고 Green을 연결/활성 상태에만 사용한다. 파형이 record card로 변환되는 Flow Motif를 KV에서 시작해 카드뉴스의 페이지 연결, 부스 동선, 웹 Section transition까지 일관되게 확장한다.

색상 값은 포트폴리오 콘셉트용 시작안이며 공식 브랜드 컬러가 아니다. 로고는 공식 파일을 확보한 뒤 원형을 변경하지 않고 사용한다.

## Hero Work 5개

1. Master Key Visual: 캠페인의 감정·기술·그래픽 시스템을 한 장에 압축
2. Kakao VET Card News: 모바일 정보 위계와 연속 콘텐츠 역량
3. Seminar / Conference Package: KV, 대형 스크린, X배너, 부스의 공간 확장
4. Campaign Landing Page: 반응형 UI와 scroll presentation 구현 기반
5. AI-assisted Visual Workflow: 생성, 선별, Photoshop retouch, 매체 variation의 디자이너 통제 과정

Newsletter, Leaflet, Catalog Sample은 완성도 있는 Variation으로 묶는다. 별도 Hero로 늘리지 않는다.
