# OFFBEAT — Original Music Release & Content Brand

## Project 01
| 항목 | 정의 |
| --- | --- |
| Category | Original Music · Release Content · Digital Content Planning |
| Type | Personal Concept Project |
| Year | 2026 |
| Role | Content Planning · Music Direction · Content Direction · Visual Planning · AI-assisted Production |

OFFBEAT은 Original Music을 기획·제작하고, 각 곡의 콘셉트와 비주얼 콘텐츠를 설계해 하나의 Digital Release로 완성하는 개인 Music Content Brand 프로젝트입니다.

실제 회사나 음원 유통사가 아닙니다. 판매·유통·청취 성과를 주장하지 않습니다.
Music Release / Music Content / Release Campaign / Digital Content / Original Music을 사용합니다.
Original Music은 이 프로젝트의 콘텐츠 분류이며, AI 미사용 또는 권리·유통 검증 완료를 뜻하지 않습니다.

## Content System
| 단계 | 목적 |
| --- | --- |
| MUSIC | 주제·장르·사운드·보컬 방향 기획, AI-assisted Production으로 음악 제작 |
| IDENTITY | 곡의 감정·메시지·분위기와 콘텐츠 방향 정의 |
| VISUAL | Cover Artwork · Key Visual · Release Visual |
| CONTENT | Social Feed · Lyric Content · Carousel · Short-form Teaser |
| RELEASE | 음악과 비주얼을 Release Package로 구성하고 청취 경험에 연결 |

MUSIC → IDENTITY → VISUAL → CONTENT → RELEASE

## Release System
- OFFBEAT = Brand / Content System
- RELEASE 001 = 저장한 노래 / SAVED SONG
- RELEASE 002 / 003 = 향후 확장 번호. 곡·제목·자산 미정이며 실제 Release로 표시하지 않습니다.
- Release 번호는 개인 프로젝트의 콘텐츠 체계입니다. 외부 유통 등록이나 발매일을 의미하지 않습니다.

## Previous Direction — 폐기한 기획
기존 Digital Music Curation / Mood × Moment × Taste / Music Discovery는
다른 아티스트의 음악을 감정과 상황에 따라 추천하는 설정이었습니다.
20–30s Digital Music Listeners 타깃, Too Much Music / Too Little Discovery 문제,
MOOD DROP / AFTER MIDNIGHT / ONE ARTIST / IF YOU LIKE / 15 SEC DISCOVERY 추천 포맷,
Playlist discovery와 Instagram 큐레이션 계정 설정을 폐기합니다.
기존 4주 큐레이션 캘린더와 FIND YOUR OFFBEAT 카피는 새 Release 전략의 확정안으로 승계하지 않습니다.
새 브랜드 카피는 별도 확정합니다.

변경 이유: 음악 추천에서 직접 기획·제작한 음악을 Visual / Social / Short-form / Web으로 확장하는
Release Content Package로 프로젝트 중심을 옮깁니다.
기존 작업·검증 기록과 Git history는 보존합니다.
